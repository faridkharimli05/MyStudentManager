# StudentManagerApp

A professional Java console application for managing student records. This application demonstrates core Java concepts including classes, objects, lists, and basic CRUD operations.

## Features

- Add, remove, update, and deactivate students
- Search and list students
- Clear all students
- Interactive console-based menu for user-friendly experience
- Automatic ID assignment for each student

## Project Structure

- `Student.java` → Represents a student with fields like ID, name, group, score, and active status.
- `StudentManager.java` → Handles all student operations including add, remove, update, deactivate, search, show all, and clear all.
- `Main.java` → Provides an interactive console interface for users to manage students.
